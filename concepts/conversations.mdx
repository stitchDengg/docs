---
title: "Conversations: persistent, user-scoped chat sessions"
description: "A conversation stores your full message history with the AI. Learn how to create, manage, and delete conversations through the Claw Agent API."
---

A conversation is a named, persistent session that holds the complete exchange of messages between you and the AI. Every message you send and every reply the AI generates is saved inside a conversation, so you can pick up exactly where you left off at any time. Conversations belong exclusively to you — you can only see and manage your own.

## What a conversation contains

Each conversation has the following fields:

| Field       | Description                                                         |
| ----------- | ------------------------------------------------------------------- |
| `id`        | Unique identifier (UUID) used in all API calls.                     |
| `title`     | Display name. Defaults to `"新对话"` and is automatically set from the first 30 characters of the AI's first response. |
| `createdAt` | Timestamp when the conversation was created.                        |
| `updatedAt` | Timestamp of the most recent message or rename.                     |

Messages inside a conversation carry a `role` field that tells you who wrote each one:

- **`user`** — messages you sent.
- **`assistant`** — responses generated by the AI.

## Managing conversations

You can perform the full range of CRUD operations on your conversations through the `/api/conversations` endpoints.

<Steps>
  <Step title="Create a conversation">
    Start a new session by sending a `POST` request. You can supply an optional title; if you don't, it defaults to `"新对话"`.

    ```bash
    curl -X POST https://your-domain/api/conversations \
      -H "Authorization: Bearer <token>" \
      -H "Content-Type: application/json" \
      -d '{"title": "My first chat"}'
    ```

    Save the `id` from the response — you need it when sending messages.
  </Step>

  <Step title="List all conversations">
    Retrieve every conversation you own, ordered by the most recently updated.

    ```bash
    curl https://your-domain/api/conversations \
      -H "Authorization: Bearer <token>"
    ```
  </Step>

  <Step title="View a single conversation">
    Fetch a specific conversation and its messages by `id`.

    ```bash
    curl https://your-domain/api/conversations/<id> \
      -H "Authorization: Bearer <token>"
    ```
  </Step>

  <Step title="Rename a conversation">
    Update the title of any conversation you own with a `PATCH` request.

    ```bash
    curl -X PATCH https://your-domain/api/conversations/<id> \
      -H "Authorization: Bearer <token>" \
      -H "Content-Type: application/json" \
      -d '{"title": "LangGraph deep dive"}'
    ```
  </Step>

  <Step title="Delete a conversation">
    Permanently remove a conversation with a `DELETE` request. This action cannot be undone.

    ```bash
    curl -X DELETE https://your-domain/api/conversations/<id> \
      -H "Authorization: Bearer <token>"
    ```

    A successful delete returns `204 No Content`.
  </Step>
</Steps>

## Conversation history as context

When you send a new message, Claw Agent automatically loads the full message history from the conversation and passes it to the AI. This means the AI always has the context of what was said earlier — you don't need to re-explain background information on every turn.

<Tip>
  Long conversations carry more context tokens with each request. If you notice slower responses on very long sessions, starting a fresh conversation can improve speed.
</Tip>

## Cascade deletes

Deleting a conversation permanently removes all of its messages at the same time. There is no way to recover deleted messages or conversations, so make sure you no longer need a conversation before deleting it.

<Warning>
  `DELETE /api/conversations/<id>` is irreversible. All messages in the conversation are deleted immediately.
</Warning>
