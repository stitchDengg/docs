Claw Agent is an AI chat assistant powered by the MiniMax language model. It keeps track of your full conversation history, streams responses token-by-token as the model thinks, and can invoke built-in tools on your behalf — so you always see results in real time instead of waiting for a complete reply.

## Key features

  <Card title="Streaming responses" icon="bolt">

  <Card title="Multi-turn conversations" icon="messages">

  <Card title="Built-in tools" icon="wrench">

## Built-in agent tools

The agent decides on its own when to call a tool. You do not need to invoke them explicitly — just ask a question that requires one.

| Tool | What it does |
| --- | --- |
| `get_weather` | Returns current temperature, conditions, humidity, and wind for a city |
| `calculate` | Evaluates arithmetic expressions (e.g. `(10 + 5) * 2`) |
| `search_knowledge` | Looks up topics such as Python, TypeScript, React, Next.js, and LangGraph |

## Two ways to use Claw Agent

**Web app** — Open the browser UI at your deployment's port 3000. Register an account, create a conversation, and start chatting. Responses stream directly into the chat window and are rendered as Markdown.

**REST API** — Use any HTTP client to call the JSON API directly. This is useful for integrating Claw Agent into your own application, running automated scripts, or exploring responses programmatically.

<Note>
  Both interfaces share the same backend. Conversations you create via the API appear in the web UI, and vice versa.
</Note>
