Claw Agent is an AI chat assistant that delivers real-time streaming responses, maintains full conversation history, and comes equipped with built-in tools for weather lookup, math calculations, and knowledge search. Whether you're using the web interface or calling the REST API directly, Claw Agent gives you a fast, context-aware AI assistant backed by the MiniMax LLM.

## Get started in four steps

<Steps>
  <Step title="Create an account">
    Register at the Claw Agent web app or call `POST /api/auth/register` with a username and password.
  </Step>
  <Step title="Log in and get your token">
    Call `POST /api/auth/login` to receive a JWT access token. Include it as `Authorization: Bearer <token>` on every subsequent request.
  </Step>
  <Step title="Create a conversation">
    Call `POST /api/conversations` to open a new chat session. Save the returned `id` — you'll use it when sending messages.
  </Step>
  <Step title="Start chatting">
    Send a message to `POST /api/chat` with your `conversationId` and `message`. The response streams back token-by-token in real time.
  </Step>
</Steps>
